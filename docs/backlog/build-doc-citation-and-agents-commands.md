# Build doc citation and agents commands

## Problem

`doc` writes most of the adjacent-files ring (`readme`, `contributing`,
`security`, `support`, `license`, `code-of-conduct`) but has no command for
`CITATION.cff` or `AGENTS.md`.

## Outcome

`doc citation new` (Citation File Format 1.2.0) and `doc agents new` exist,
once their input shapes are fixed.

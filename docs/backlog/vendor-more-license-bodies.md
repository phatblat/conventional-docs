# Vendor more license bodies

## Problem

The embedded standards pack carries only Apache-2.0, BSD-2-Clause,
BSD-3-Clause, GPL-3.0-or-later, ISC, MIT, MPL-2.0, and Unlicense. A repository
that wants a license outside that set has no embedded body to copy from.

## Outcome

More license bodies are vendored into the embedded standards pack, starting
with the SPDX list's next-most-requested identifiers.

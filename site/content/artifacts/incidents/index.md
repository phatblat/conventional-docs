What broke, what we learned.

- Paths: none at the root — an incident only exists graduated, at
  `docs/incidents/YYYY-MM-DD-slug.md`, one file per incident.
- Lifetime: append-only — not rewritten after the incident closes, except to
  append follow-up references.
- Answers: what broke, what we learned.

This project doesn't operate a running system and doesn't use incident
records yet — see the Charter's own
[`## Artifacts`](https://github.com/phatblat/conventional-docs/blob/main/CHARTER.md#artifacts)
table. A project that does writes one record per incident, covering the
timeline, the root cause, and any follow-ups the Roadmap should track.

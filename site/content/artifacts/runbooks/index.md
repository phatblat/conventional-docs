What to do when a named alarm fires.

- Paths: none at the root — a runbook only exists graduated, at
  `docs/runbooks/<trigger>.md`, one file per trigger.
- Lifetime: living.
- Answers: what to do when _x_ fires.

This project doesn't operate a running system and doesn't use runbooks yet —
see the Charter's own
[`## Artifacts`](https://github.com/phatblat/conventional-docs/blob/main/CHARTER.md#artifacts)
table. A project that pages someone writes one runbook per alarm it operates,
covering symptoms, diagnosis, and mitigation, for whoever is paged.
